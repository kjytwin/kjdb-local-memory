# 안정판 출시 합격 조건

대상: Windows x64, 로컬 텍스트 메모리, Codex CLI / 독립 Claude Code CLI /
Claude Desktop 일반 채팅. MIT 라이선스는 유지한다.

## 필수 검증

1. 출시 소스에서 production/fault DLL을 빌드하고 전체 회귀 테스트를 실행한다.
   별도 GitHub Windows runner에서도 실행하며 실패와 SKIP을 공개한다.
2. 실제 배포 ZIP을 풀어 번들 Python으로 검사한다. 세 앱에서 실제 모델의
   저장과 새 세션 재조회를 확인한다. 설정 생성이나 직접 MCP 호출은 이 증거를
   대신하지 않는다. 정확한 패키지 해시, 앱 버전과 결과를 기록한다.
3. 기존 미리보기 데이터의 읽기, 새 버전 기록, 백업 복원 및 이전 버전 재열기를
   검사한다. 손상 데이터는 보존하고 거부한다. 한도 도달 시 기존 데이터를
   보존하는지 검사한다. 실행 시간과 횟수를 기록하며 장기 실사용으로 표현하지 않는다.
4. 자체 검토 두 차례와 가상 관리자 박서준의 지적 최대 세 개를 기록한다.
   실제 결함은 수정하고 재발 방지 규칙을 추가한다.
5. 설치·업데이트·백업·복구·제한사항을 문서화한다. 모든 필수 결과가 확인된
   동일 소스만 안정판 태그와 릴리스로 게시한다. 미완료 항목이 있으면 미리보기를 유지한다.

## 지원 제외

- Claude Desktop Cowork 및 내장 Code, 다중 서버의 동일 프로젝트 동시 소유
- 의미 검색, 자동 대화 수집, 암호화 및 안전한 물리 삭제
- 물리 전원 차단 내구성, 임의의 악성 경로 교체에 대한 보장
- 검증하지 않은 운영체제·아키텍처와 무기한 무중단 운영 보장

이 제외 범위는 기존 미리보기의 제한을 명시한 것이며 검사 결과를 대체하지 않는다.
개인 설정, 원본 앱 로그 및 사용자 데이터는 공개 저장소에 넣지 않는다.

## 후보에서 최종 ZIP으로 승격

실제 앱 검증을 마친 후보의 runtime/native/tools 파일 집합과 SHA256을 그대로
유지하면 그 실행 코드의 앱 검증 결과를 승계한다. 최종 ZIP은 별도로 추출해 검사한다.
문서와 출시 메타데이터만 바꿀 수 있으며 실행 파일 하나라도 다르면 앱 검증을 반복한다.
