# 데이터와 개인정보

- 자동 화면·파일·대화 수집 기능이 없습니다. AI에게 명시적으로 저장을 요청한 텍스트를 처리합니다.
- KJDB 서버는 stdio를 사용하며 자체 HTTP 서버·텔레메트리·모델 API 호출을 만들지 않습니다.
- AI 앱이 KJDB에 전달하거나 조회한 텍스트는 해당 앱의 처리 경로를 따릅니다. 로컬 저장이라는 이유만으로 그 텍스트가 AI 제공자에게 전송되지 않는다고 보장하지 않습니다.
- 기본 저장소는 %LOCALAPPDATA%\KJDB\stores 아래에 있습니다. 서버의 --data-root 옵션으로 위치를 지정할 수 있습니다.
- 데이터는 암호화된 저장소가 아닙니다. 같은 사용자 권한을 가진 다른 프로그램과 컴퓨터 관리자의 접근을 막는 보안 경계로 사용하지 마세요.
- forget은 논리 삭제입니다. 원문이 파일에서 안전하게 지워진다는 뜻이 아닙니다.
- 백업·복사는 해당 프로젝트의 모든 서버를 종료한 뒤 수행합니다. 프로그램 폴더만 교체한다고 데이터가 삭제되지 않습니다.
- Issues, PR, 저장소에 실제 기억 DB·비밀키·계정 설정을 올리지 마세요. 오류 재현은 합성 자료로 만듭니다.
