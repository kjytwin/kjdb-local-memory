# 검증 범위

## 판정 원칙

이 저장소는 개발 미리보기입니다. native 저장소·MCP 직접 호출·앱 설정 생성기·실제 AI 모델 호출·기간 관찰을 각각 구분합니다.

기존 KJDB 개발 과정에서 Codex CLI와 독립 Claude Code CLI의 실제 저장·새 세션 조회, Claude Desktop 일반 채팅의 실제 저장·앱 재시작 조회를 확인했습니다. 그 결과는 당시 패키지에 한정됩니다. 이 공개용 소스 스냅샷으로 같은 앱 검증을 다시 완료했다고 주장하지 않습니다.

## 이 스냅샷의 검사

2026-10-15 공개 준비 검사: 코드 기준 4d83aa0, Windows x64 / MSVC 19.43 / Python 3.14 포함 런타임. production/fault DLL을 이 소스에서 새로 빌드했습니다.

| native 저장·중복 요청·범위 거부·버전·논리 삭제 | 통과 |
| 생성·쓰기 중단, 경쟁 생성의 기존 승자 보존 | 통과 |
| busy·손상·hardlink·symlink·junction 거부와 폴더 고정 | 통과 |
| UTF-8 stdio·초기화·오류 복구·재시작 | 통과 |
| 실제 회귀 테스트 합계 | **21/21, 실패 0, SKIP 0** |
| ZIP 파일 목록·체크섬·MIT·Python 고지·추출 런타임 | 통과 |
| 세 앱의 설정 생성과 생성된 명령의 저장·재시작·조회 | 통과 |
| 공개 파일 목록 43개·비밀값/개인 경로 패턴·Python 구문·로컬 문서 링크 | 통과 |

자동 CI도 native production/fault DLL을 새로 빌드하고 저장·복구·stdio·추출된 ZIP·세 앱의 설정 명령을 확인합니다. 이 결과는 실제 AI 앱 모델 호출의 재검증을 뜻하지 않습니다.

CI에 포함된 Python의 직접 MCP 호출은 AI 앱 모델의 실제 호출을 대체하지 않습니다. 검사 환경에서 심볼릭 링크 권한이 없다면 해당 검사는 SKIP이며 성공으로 집계하지 않습니다.

## 지원·제한

| 항목 | 범위 |
|---|---|
| Codex CLI / 독립 Claude Code CLI | 설정 생성·stdio 연결 대상 |
| Claude Desktop 일반 채팅 | 연결 대상. 새 스냅샷 실제 앱 재검증은 별도 |
| Desktop Cowork / 내장 Code | 지원 제외: 추가 인스턴스의 동일 저장소 락 충돌 |
| 저장·재시작·키워드 검색 | native/프로토콜 검사 대상 |
| 물리 전원 손실 | Windows 디렉터리 항목 내구성 미검증 |
| 임의 경로 교체·악의적 동시 파일 변경 | 일반 보안 경계로 보장하지 않음 |
| 의미 검색·암호화·보안 삭제 | 미지원 |
| 새 사용자 환경의 실제 AI 사용·장기 관찰 | 완료로 표시하지 않음 |
